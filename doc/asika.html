NAME

asika — Asika Pull Request Manager Command Line Interface

SYNOPSIS

asikad [OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS]

DESCRIPTION

Asika is a multi-platform pull request management tool. The CLI interacts with the asikad daemon to manage PRs across GitHub, GitLab, Gitea, Forgejo, Codeberg, and Bitbucket from a single interface.

GLOBAL OPTIONS

OptionDescription
-t, --token <token>JWT token or API key. Also via ASIKA_TOKEN env.
-s, --server <url>Server address (default: http://localhost:8080). Also via ASIKA_SERVER env.
-o, --output <format>Output format: table, json, yaml (default: table).

AUTHENTICATION

# JWT login (interactive)
asika login --save

# Save API key directly
asika login --api-key ak_xxx... --save

# Or set environment variable
export ASIKA_TOKEN=ak_xxx...

COMMANDS

PR Operations

asika pr list [group] [--state open|closed|merged] [--platform github|gitlab|gitea]
asika pr show [group] [id]
asika pr approve [group] [id]
asika pr close [group] [id]
asika pr reopen [group] [id]
asika pr spam [group] [id] [--undo]
asika pr comment [group] [id] [body]
asika pr rebase [group] [id]
asika pr cherry-pick [group] [id] <target-branch>
asika pr batch-approve [group] [id1,id2,...]
asika pr batch-close [group] [id1,id2,...]
asika pr batch-label [group] [id1,id2,...] --label <name> [--color <hex>]

Merge Queue

asika queue list [group]
asika queue recheck [group]
asika queue clear [group]
asika queue remove <group> <id>

API Key Management (admin only)

asika apikey create <name> <role>    # role: admin, operator, viewer
asika apikey list
asika apikey revoke <key_id>

User Management (admin only)

asika user list
asika user add <username> --password <pwd> --role <role> [--groups <g1,g2>] [--permissions <p1,p2>]
asika user update <username> [--password <pwd>] [--role <role>] [--groups <g1,g2>] [--permissions <p1,p2>] [--no-perms <p1,p2>]
asika user delete <username>

Roles: admin (full), operator (configurable), viewer (read-only).
Permissions: approve, merge, close, reopen, spam, queue.

Other Commands

asika stats                    # DORA metrics
asika usage                    # CPU/memory usage
asika config show              # Show config (secrets masked)
asika config set --file <path> # Update config
asika config reload            # Hot reload
asika rules list               # Label rules
asika stale check [group]      # Check stale PRs
asika sync history             # Sync history
asika self-update [--check]    # Self-update
asika version                  # Version info

asika - PR Manager CLI

NAME

asika - Asika Pull Request Manager Command Line Interface

SYNOPSIS

asika [OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS]

DESCRIPTION

Asika is a multi-platform pull request management tool. The CLI interacts with the asikad daemon to manage PRs across GitHub, GitLab, and Gitea platforms from a single interface.

GLOBAL OPTIONS

OptionShortDescription
--token <token>-tJWT token for authentication (or use ASIKA_TOKEN env)
--server <url>-sasikad server address (default: http://localhost:8080)
--output <format>-oOutput format: table, json, yaml (default: table)

Environment variables: ASIKA_TOKEN, ASIKA_SERVER

COMMANDS

asika completion

Generate the autocompletion script for the specified shell.

asika completion [bash|zsh|fish|powershell]

asika config

Manage asikad configuration.

SubcommandDescription
showShow current config (secrets masked)
set [--file <path>]Set config from file or stdin (TOML format)
reloadTrigger hot reload of config
# Show config
asika config show

# Set config from file
asika config set --file /path/to/config.toml

# Set config from stdin
cat config.toml | asika config set

# Reload config
asika config reload

asika init

Run configuration wizard (sends setup to server).

asika init

asika login

Login to asikad and save token for future requests.

asika login

asika pr

Manage pull requests.

SubcommandArgumentsFlagsDescription
list[group]--state open|closed|merged
--platform github|gitlab|gitea
--is_draft true|false
--author <name>
--label <label>
--created_after <time>
--updated_after <time>
--page <n>
--per_page <n>		List PRs with filters
show[group] [id]-Show PR details
approve[group] [id]-Approve PR
close[group] [id]-Close PR
reopen[group] [id]-Reopen PR
spam[group] [id]--undoMark/unmark as spam
comment[group] [id] [body]-Comment on PR
batch-approve[group] [id1,id2,...]-Batch approve PRs
batch-close[group] [id1,id2,...]-Batch close PRs
batch-label[group] [id1,id2,...]--label <name>
--color <hex>		Batch add label
# List open PRs
asika pr list my-project

# List draft PRs
asika pr list my-project --is_draft true

# Show PR details
asika pr show my-project 42

# Approve PR
asika pr approve my-project 42

# Add comment
asika pr comment my-project 42 "LGTM!"

# Batch approve
asika pr batch-approve my-project 42,43,44

# Batch add label
asika pr batch-label my-project 42,43 --label bugfix --color "#ff0000"

asika queue

Manage merge queue.

SubcommandArgumentsDescription
list[group]Show merge queue
recheck[group]Trigger queue recheck
# List queue
asika queue list my-project

# Trigger recheck
asika queue recheck my-project

asika rules

Manage label rules (auto-labeling by file patterns).

asika rules [SUBCOMMAND]

asika self-update

Update asika/asikad to the latest version.

FlagDescription
--version <tag>Install specific version
--checkOnly check for updates
--dry-runPreview without changes
--yesSkip confirmation
--rollbackRollback to previous version
--restartRestart in-place after update
# Check for updates
asika self-update --check

# Update to latest
asika self-update

# Dry run
asika self-update --dry-run

# Rollback
asika self-update --rollback

asika stale

Manage stale PRs.

SubcommandArgumentsFlagsDescription
check[group]--dry-runCheck for stale PRs
unmark[group] [id]-Remove stale label

asika sync

Manage sync history (multi mode).

SubcommandDescription
historyShow sync history
retry [sync_id]Retry failed sync

asika user

Manage users (admin only).

asika version

Print version information.

asika version
Asika version 20260504DEV

CONFIGURATION

CLI config is stored at ~/.config/asika/config.json with token and server settings.

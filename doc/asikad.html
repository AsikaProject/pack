NAME

asikad — Asika Daemon with merge queue, web dashboard, and bot integrations

SYNOPSIS

asikad [OPTIONS]

DESCRIPTION

The asikad daemon provides the backend for Asika PR management. It handles merge queue processing, web dashboard, webhook events, and bot integrations (Telegram, Feishu, Discord, Slack).

OPTIONS

OptionDescription
-desktopRun in desktop foreground mode. Opens browser to WebUI automatically.
-versionPrint version and exit.

ENVIRONMENT

VariableDescription
ASIKA_CONFIGPath to configuration file. Default: /etc/asika_config.toml

CONFIGURATION

Configuration is stored in TOML format. See asika.toml.example for full reference.

Server Configuration

[server]
listen = ":8080"
mode = "release"
enable_web_update = true

Database

[database]
path = "/var/lib/asika/asika.db"

Authentication

[auth]
jwt_secret = "secret"
token_expiry = "72h"

Bot Integrations

[telegram]
enabled    = true
token      = "bot-token"
admin_ids    = [12345678]
operator_ids = [11111111]
viewer_ids   = [22222222]

[feishu]
enabled      = true
app_id       = "cli_xxx"
admin_ids    = ["ou_xxx"]
operator_ids = ["ou_yyy"]

[discord]
enabled      = true
token        = "discord-token"
admin_ids    = ["user_id_1"]
operator_ids = ["user_id_2"]

[slack]
enabled      = true
token        = "xoxb-token"
admin_ids    = ["U0123456789"]
operator_ids = ["U0987654321"]

API ENDPOINTS

Authentication

POST /api/v1/auth/login — Login with username/password. Returns JWT token.
POST /api/v1/auth/logout — Logout (blacklists JWT token).

PR Management

GET /api/v1/repos/:group/prs — List PRs. Requires: viewer+ role, repo group access.
GET /api/v1/repos/:group/prs/:id — Get PR details. Requires: viewer+ role.
POST /api/v1/repos/:group/prs/:id/approve — Approve PR. Requires: approve permission.
POST /api/v1/repos/:group/prs/:id/close — Close PR. Requires: close permission.
POST /api/v1/repos/:group/prs/:id/reopen — Reopen PR. Requires: reopen permission.
POST /api/v1/repos/:group/prs/:id/spam — Mark as spam. Requires: spam permission.
POST /api/v1/repos/:group/prs/:id/rebase — Rebase PR. Requires: merge permission.
POST /api/v1/repos/:group/prs/:id/cherry-pick — Cherry-pick merged PR. Requires: merge permission.
POST /api/v1/repos/:group/prs/batch/approve — Batch approve. Requires: approve permission.
POST /api/v1/repos/:group/prs/batch/close — Batch close. Requires: close permission.
POST /api/v1/repos/:group/prs/batch/label — Batch label. Requires: viewer+ role.

Queue Management

GET /api/v1/queue/:group — Get merge queue. Requires: viewer+ role.
POST /api/v1/queue/:group/recheck — Trigger queue recheck. Requires: manage_queue permission.
DELETE /api/v1/queue/:group — Clear queue. Requires: manage_queue permission.
DELETE /api/v1/queue/:group/:id — Remove from queue. Requires: manage_queue permission.

User Management (admin only)

GET /api/v1/users — List all users.
POST /api/v1/users — Create user.
PUT /api/v1/users/:username — Update user.
DELETE /api/v1/users/:username — Delete user.

API Key Management (admin only)

POST /api/v1/apikeys — Create API key. Returns key with raw secret (shown once).
GET /api/v1/apikeys — List all API keys (raw secrets not shown).
DELETE /api/v1/apikeys/:id — Revoke API key.

Stats & Usage

GET /api/v1/stats — DORA metrics and overview statistics. Requires: any authenticated user.
GET /api/v1/usage — Real-time CPU and memory usage. Requires: any authenticated user.

Configuration (admin only)

GET /api/v1/config — Get current config (secrets masked).
PUT /api/v1/config — Update config (hot-reloadable).
GET /api/v1/config/history — Config version history.
POST /api/v1/config/rollback — Rollback config.

Admin Operations

POST /api/v1/admin/backup — Create database backup.
GET /api/v1/admin/backups — List backups.
POST /api/v1/admin/restore — Restore from backup.

Health Check

GET /health — Health check (no auth required).

AUTHENTICATION

Two authentication methods are supported:

MethodHeaderDescription
JWT (Bearer)Authorization: Bearer <token>Obtained via POST /api/v1/auth/login. Default expiry: 72h.
API KeyX-API-Key: <key>Long-lived key for CI/CD. Created via POST /api/v1/apikeys (admin only). Format: ak_ + 64 hex chars.

BOT COMMANDS

All four bot platforms (Telegram, Feishu, Discord, Slack) support the same command structure:

User Management (admin only)

adduser <username> <password> <role> [groups]
deluser <username>
listusers

API Key Management (admin only)

apikey new <name> <role>
apikey list
apikey revoke <key_id>

API keys are delivered via DM and auto-deleted after 2 minutes.

PR Operations

prs [group]           List PRs
pr <group> <id>       Show PR details
approve <group> <id>  Approve PR
close <group> <id>    Close PR
reopen <group> <id>   Reopen PR
spam <group> <id>     Mark as spam

Queue Operations

queue [group]         Show merge queue
recheck               Trigger queue recheck
queue_clear           Clear queue

System

stats                 DORA metrics
usage                 CPU/memory usage
config                Show config summary
version               Show version info
help                  Show all commands

INSTALLATION

# Copy binary
cp asikad /usr/local/bin/

# Install systemd service
cp pack/debian/asikad.service /etc/systemd/system/

# Enable and start
systemctl enable asikad && systemctl start asikad

asikad - Asika Daemon

NAME

asikad - Asika Daemon with merge queue, web dashboard, and bot integrations

SYNOPSIS

asikad [OPTIONS]

DESCRIPTION

The asikad daemon provides the backend for Asika PR management. It handles:

  • Merge Queue - Automated PR merging with approval/CI checks
  • Web Dashboard - Browser-based PR management interface
  • Webhook Handler - Receives events from GitHub/GitLab/Gitea
  • Bot Integrations - Telegram, Feishu, Discord interactive bots
  • Spam Detection - Automatic spam PR detection
  • Stale PR Management - Auto-label and close stale PRs

OPTIONS

OptionDescription
-desktopRun in desktop foreground mode (opens browser to WebUI automatically)
-versionPrint version and exit

ENVIRONMENT

VariableDescriptionDefault
ASIKA_CONFIGPath to config file/etc/asika_config.toml

CONFIGURATION

Configuration is stored in TOML format at /etc/asika_config.toml (or path specified by ASIKA_CONFIG).

Server Configuration

[server]
listen = ":8080"          # Listen address
mode = "release"         # "release" or debug
enable_web_update = true  # Allow self-update from web UI

Database

[database]
path = "/var/lib/asika/asika.db"

Authentication

[auth]
jwt_secret = "your-secret-here"
token_expiry = "72h"

Platform Tokens

[tokens]
github = "ghp_xxx"    # GitHub personal access token
gitlab = "glpat-xxx"  # GitLab personal access token
gitea = "gitea_xxx"  # Gitea token

Events (Webhook/Polling)

[events]
mode = "webhook"           # "webhook" or "polling"
webhook_secret = "secret"   # Webhook signing secret
polling_interval = "5m"    # Polling interval (for polling mode)

Merge Queue

[merge_queue]
required_approvals = 1
ci_check_required = true
core_contributors = ["user1", "user2"]

[[repo_groups]]
name = "my-project"
mode = "single"            # "single" or "multi"
github = "owner/repo"
default_branch = "main"

Spam Detection

[spam]
enabled = true
time_window = "10m"
threshold = 3
trigger_on_author = true
trigger_on_title_kw = ["spam", "fix typo"]

Stale PR Management

[stale]
enabled = true
check_interval = "6h"
days_until_stale = 21
days_until_close = 0      # 0 = never close
stale_label = "stale"
exempt_labels = ["long-term"]
notify_on_stale = true
skip_draft_prs = true

Bot Integrations

# Telegram
[telegram]
enabled = true
token = "bot-token"
admin_ids = [123456]

# Feishu/Lark
[feishu]
enabled = true
app_id = "cli_xxx"
app_secret = "xxx"

# Discord
[discord]
enabled = true
token = "discord-bot-token"
channel_id = "123456"

API ENDPOINTS

Authentication

POST /api/v1/auth/login - Login with username/password
POST /api/v1/auth/logout - Logout

PR Management

GET /api/v1/repos/:group/prs - List PRs (filters: state, is_draft, author, label, etc.)
GET /api/v1/repos/:group/prs/:id - Get PR details
POST /api/v1/repos/:group/prs/:id/approve - Approve PR
POST /api/v1/repos/:group/prs/:id/close - Close PR
POST /api/v1/repos/:group/prs/:id/reopen - Reopen PR
POST /api/v1/repos/:group/prs/:id/spam - Mark as spam
POST /api/v1/repos/:group/prs/:id/comment - Comment on PR
POST /api/v1/repos/:group/prs/batch/approve - Batch approve
POST /api/v1/repos/:group/prs/batch/close - Batch close
POST /api/v1/repos/:group/prs/batch/label - Batch label

Queue Management

GET /api/v1/queue/:group - Get merge queue
POST /api/v1/queue/:group/recheck - Trigger recheck

Audit Logs

GET /api/v1/logs - Get audit logs (?level=info|warn|error)

Configuration

GET /api/v1/config - Get config (admin only)
PUT /api/v1/config - Update config (admin only, hot-reloadable)

Self-Update

GET /api/v1/self-update/check - Check for updates
GET /api/v1/self-update/run - Perform update (SSE progress)

Webhooks (No Auth)

POST /webhook/:group/:platform - Receive platform webhooks
POST /api/v1/feishu/event - Feishu event callback

Health Check

GET /health - Health check

WEB DASHBOARD

The web dashboard is available at the server address (default: http://localhost:8080).

  • Wizard (/wizard) - First-time setup
  • Login (/login) - User authentication
  • Dashboard (/dashboard) - Statistics and overview
  • PR List (/prs) - Browse and filter PRs
  • PR Detail (/prs/:id) - PR details and actions
  • Queue (/queue) - Merge queue management
  • Users (/users) - User management (admin)
  • Config (/config) - Configuration editor (admin)

INSTALLATION

# Build from source
git clone https://github.com/minibp/asika.git
cd asika
bash build.sh

# Install binaries
sudo cp asika asikad /usr/local/bin/

# Setup systemd service (Linux)
sudo cp pack/debian/asikad.service /etc/systemd/system/
sudo systemctl enable asikad
sudo systemctl start asikad
